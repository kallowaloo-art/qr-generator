# Signal QR Generator

This repository now contains a small static Signal QR generator app (client-side). It generates a Signal link QR code from a phone number.

Run locally:
- Open index.html in your browser, or run a local static server:
  - Python: python -m http.server 3000
  - Node: npx serve .

Deploy to Vercel:
- Vercel serves static sites from the repository root. The site is already placed at the root — push/merge the branch to your deployment branch (usually main) and Vercel will build.
